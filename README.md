# AI-Enabled Enterprise Inventory Analytics System

Problem
Businesses need efficient inventory management and sales insights.

Solution
Built a Python and SQL Server application that manages inventory, processes orders,
analyzes sales data, and predicts future demand.

---

# Project Overview

This system simulates how companies manage:

- Product inventory
- Customer orders
- Stock updates
- Order processing workflows

The application connects Python with Microsoft SQL Server and performs backend operations such as:

- Creating products
- Managing stock
- Creating customer orders
- Reducing inventory automatically
- Storing order history

---

# Technologies Used

- Python 3
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- pyodbc
- Git & GitHub
- Object-Oriented Programming (OOP)
- Pandas
- Matplotlib
- Scikit-Learn
